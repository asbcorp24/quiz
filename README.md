# MicroFeedback

Небольшой сайт обратной связи на PHP + Bootstrap в стиле микроэлектроники.

## Возможности
- Создание отдельных опросов в админке.
- Для каждого опроса создаётся уникальная ссылка и QR-код.
- QR можно показать и скачать PNG.
- Форма: оценка 1–5, комментарий до 300 символов, дата/время, 1–3 фото.
- Загруженные фото автоматически уменьшаются до границ 640×480 с сохранением пропорций.
- Админка: общая статистика, средняя оценка, негативные оценки, графики, журнал отзывов, фильтры, просмотр фото.
- SQLite — отдельный MySQL не нужен.

## Требования
- PHP 8.1+
- PDO SQLite
- расширения fileinfo и GD
- права PHP на запись в `data/` и `uploads/`

## Установка
1. Скопировать папку проекта на сервер.
2. Убедиться, что PHP может писать в `data` и `uploads`.
3. Открыть `/admin/login.php`.
4. Вход по умолчанию:
   - логин: `admin`
   - пароль: `admin123`
5. ОБЯЗАТЕЛЬНО поменять `ADMIN_PASSWORD` в `config.php`.
6. В админке открыть «QR / Опросы», создать опрос и распечатать QR.

База `data/app.sqlite` создастся автоматически при первом обращении.

## Важно
Bootstrap, Chart.js и библиотека QRCode подключены через CDN. Если нужен полностью автономный вариант без Интернета, скачайте эти библиотеки в `assets/vendor/` и замените ссылки.
